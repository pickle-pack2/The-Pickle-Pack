PICKLE PACK WEBSITE — QUICK START

FILES
- index.html: website content
- styles.css: colors, layout, and mobile-responsive design
- script.js: mobile menu and Facebook links
- assets/pickle-pack-logo.jpeg: uploaded Pickle Pack logo

BEFORE PUBLISHING
1. Open script.js in a text editor.
2. Your provided Facebook link is already added in script.js.
3. Review event details in index.html and update any dates, fees, or availability that change.

PREVIEW ON YOUR COMPUTER
- Keep the files in the same folder structure.
- Open index.html in a browser. Internet is needed for the optional Google Fonts import.

PUBLISH FOR FREE (GitHub Pages)
1. Sign in or create an account at https://github.com/
2. Create a new public repository, e.g. pickle-pack-website.
3. Upload index.html, styles.css, script.js, README.txt, and the assets folder with the logo.
4. In the repository, open Settings → Pages.
5. Under Build and deployment, choose Deploy from a branch; select main and /(root), then Save.
6. Wait for GitHub Pages to publish. Your website URL will appear in the Pages settings.

Alternative: Netlify
1. Sign in at https://www.netlify.com/
2. Use Add new site / deploy manually (wording may vary).
3. Drag the whole pickle_pack_website folder into the upload area.
4. Netlify will provide a public website URL.

NOTES
- The website is a static site; it does not collect personal data or take payments.
- Registration buttons open your Facebook page after you add its URL.
- Event details are based on the club information currently available and should be checked before going live.
- A custom domain is optional and may cost extra.
